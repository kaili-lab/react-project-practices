# 这个文件是 CSS 模块，用于描述用户头像的样式

## 实现左上角和右下角的背景图

1. 为什么使用伪元素来实现？
   因为它们是装饰性元素，不属于内容；

2. 为什么使用 background-image 来实现？

   1. 语义上：这是“背景”，不是“内容图片”，不承载信息，不需要 alt 文本；
   2. 这种情况，用 CSS background-image 比 `<img>` 更合理：

3. 伪元素设置 width 和 height 之后是方形的，而最终看到的是弧形？
   1. 因为方形本身没有颜色，看到的弧形是原本背景图的形状；

## 实现头像周围的圆环

1. 多添加一层 div，
   用白色背景，设为圆形；
   使用 flex 实现居中效果；
   比内层稍大的半径；
2. 内层的 div 设为圆形，设置一个略小的直径；
   这个内层主要用来让图片变圆；
